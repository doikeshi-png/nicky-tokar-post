nicky tokar — Telegram Rich Post Builder

Как использовать:
1. Вставьте токен бота.
2. Вставьте название канала, например @channel_name.
3. Напишите заголовок и текст поста.
4. Выберите оформление.
5. Нажмите «Выложить пост в Telegram».

Важно: для карусели и коллажа нужны прямые публичные HTTPS-ссылки на файлы .jpg, .png, .mp4.
